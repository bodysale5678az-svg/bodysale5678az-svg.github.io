About me

Backend-first, clean-code mindset.

Student, developer, and community leader — learning by building real systems.

I'm Mahmoud Waleed Mohamed Saleh, a Computer Science student at Akhbar El-Youm Academy and a freelance backend developer working with C# and .NET. My focus is on object-oriented design, clean software structure, and writing code that stays maintainable as a project grows.

I started with C and C++, moved through data structures and OOP, and now build backend applications with .NET. My best example of that progression is the Anqoodi Store project — rebuilt four times across four stages, from a C++ prototype to a full .NET backend.

Beyond code, I lead the NEC Community at Akhbar El-Youm Academy, where I oversee both the technical and non-technical tracks and teach C++ as an instructor in the DSC activity.
